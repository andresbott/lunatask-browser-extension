Necessary for creating tasks/notes on your behalf. From anywhere in Lunatask desktop, click the settings icon in the top right, then open "Access tokens" and click "Create access token". Rename it to something like "Browser extension", then click "Copy to clipboard".

If blank, the extension will only be able to save page content to notes. If provided, it can create tasks in this area. To find the ID, start from the Tasks tab, go to the area, click the settings icon in the top left, then click "Copy ID" in the bottom left.

If provided, create tasks in this goal. To find the ID, start from the Tasks tab, go to the goal, click "Edit goal" to the right of the goal's name, then click "Copy ID" in the bottom left.

If blank, create notes without a notebook. If provided, create them with a notebook. To find the ID, start from the Notes tab, open the notebook selector, click the settings icon to the right of the notebook, then click "Copy ID" in the bottom left.
